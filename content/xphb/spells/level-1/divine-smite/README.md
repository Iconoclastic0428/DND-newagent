# Divine Smite

XPHB level-1 spell rollout entry. Runtime support mode: `deterministic-capability`.

Cast syntax: `/attack player-1 <melee-weapon> <target> then /react player-1 divine-smite:player-1:divine-smite`

Local XPHB use case: Deterministic post-hit bonus-action spell trigger on a melee weapon hit or unarmed strike.
