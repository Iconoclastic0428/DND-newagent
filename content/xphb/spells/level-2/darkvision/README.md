# Darkvision

Status: deterministic-capability

Cast syntax:
- `/cast player-1 darkvision player-1`

Summary:
- Exact XPHB Darkvision gives a touched willing creature 150 feet of darkvision for 8 hours.
- The effect changes what the target can see in darkness; it does not change lighting or bypass heavy obscurement.

See `IMPLEMENTATION.md` for the exact runtime behavior and edge cases.
