# Cloud of Daggers

This item directory is an honest blocker shell.

The local XPHB text is present in the repository mirror, but exact runtime support still needs a movable persistent-zone primitive. The current rules engine can create persistent areas, but it cannot yet re-anchor the zone with the spell's action-based movement clause while preserving exact once-per-turn damage semantics.

Cast syntax:

`/cast player-1 cloud-of-daggers 5 2`
