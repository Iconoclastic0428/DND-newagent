# Cordon of Arrows

This item directory is an honest blocker shell.

The local XPHB text is present in the repository mirror, but exact runtime support still needs an armed ward primitive with charge depletion and proximity-triggered damage. The current runtime can place persistent areas, but it cannot yet model four planted arrows that fire one-by-one and terminate the spell when all are expended.

Cast syntax:

`/cast player-1 cordon-of-arrows player-1`
