# Flaming Sphere

This item directory is an honest blocker shell.

The local XPHB text is present in the repository mirror, but exact runtime support still needs a movable damaging sphere primitive. The current runtime can create persistent areas, but it cannot yet move the sphere as a bonus action, stop movement when it enters a creature's space, and handle the related ignition behavior exactly.

Cast syntax:

`/cast player-1 flaming-sphere 5 2`
