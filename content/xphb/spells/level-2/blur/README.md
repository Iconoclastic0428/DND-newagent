# Blur

Status: deterministic-capability

Cast syntax:
- `/cast player-1 blur`

Summary:
- Exact XPHB Blur makes attacks against the caster have disadvantage for 1 minute while concentration lasts.
- Attackers using blindsight or truesight to perceive the caster are immune to this spell's effect.

See `IMPLEMENTATION.md` for the exact runtime behavior and edge cases.
